# Security policy

## Supported versions

Fixes go into the latest release. Older releases get none.

## Reporting a vulnerability

Report it privately through GitHub:
[open a security advisory](https://github.com/peekaboot-org/peekaboot/security/advisories/new).
Do not open a public issue for it.

Say which version you run, how to reproduce it and what an attacker gains. You get an answer
within seven days. A confirmed report is fixed in a release, and the advisory is published with
it and credits you unless you ask otherwise.

What Peekaboot guards, what it masks and what it writes to disk is described under
[Security](https://www.peekaboot.org/docs/security/).
